# RD Autopeças

Sistema ERP Full Stack para gerenciamento de uma loja de autopeças, desenvolvido com **Java, Spring Boot e React Native**. O projeto tem como objetivo ser um ambiente de negócio real.

## Tecnologias

### Backend
- Java 21
- Spring Boot
- Spring Data JPA (Hibernate)
- Spring Security
- Lombok
- Flyway
- Cucumber
- Junit 4

### Banco de Dados
- PostgreSQL

### Frontend Web
- React 
- Vite
- TypeScript
- React Router, React Icons, React Lucide
- Shad Cn

## Documentação da API

A documentação da API está disponível através do **Swagger** após iniciar a aplicação:

```
http://localhost:8080/swagger
```
